下载说明

海外用户

推荐优先使用 GitHub；若 GitHub 当前网络异常，可切换 GitLab 备用镜像继续下载。

中国大陆用户

建议优先测试 GitHub；若当前网络对 GitHub 不稳定，可尝试 GitLab 备用下载。Gitee 原始文件大包下载目前不稳定。

系统要求

Android 设备下载安装后，需要允许当前来源安装未知应用。

安装步骤

  1. 优先点击“GitHub 下载 APK”；如果下载异常，再尝试“GitLab 备用下载”。
  2. 首次安装时，在系统设置中允许浏览器或聊天工具“安装未知应用”。
  3. 安装完成后打开 NVRClient，按提示授予相机、麦克风和网络相关权限。
  4. 如果你需要扫码添加设备，请确保设备二维码清晰可见，并允许相机权限。
